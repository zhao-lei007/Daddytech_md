# 云同步功能使用指南

## 🌟 功能概述

云同步功能允许您在多个设备之间同步微信 Markdown 编辑器的所有数据，包括：

- 📝 所有文章内容和历史记录
- 🎨 主题设置和自定义样式
- ⚙️ 编辑器配置和偏好设置
- 🤖 AI 配置和快捷指令
- 🔐 敏感数据加密保护

## 🚀 支持的同步方式

### 1. Supabase 云同步 (推荐)

**优点：**

- ✅ 实时同步，多设备无缝切换
- ✅ 数据加密，保护隐私安全
- ✅ 自动冲突检测和解决
- ✅ 免费额度充足，稳定可靠
- ✅ 支持离线使用，联网时自动同步

**配置步骤：**

#### 第一步：创建 Supabase 项目

1. 访问 [Supabase](https://supabase.com) 并注册账号
2. 点击 "New Project" 创建新项目
3. 填写项目名称和密码
4. 等待项目创建完成（约2分钟）

#### 第二步：获取连接信息

1. 在项目仪表板中，点击左侧 "Settings" → "API"
2. 复制以下信息：
   - **Project URL**: 形如 `https://xxx.supabase.co`
   - **anon public key**: 以 `eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9` 开头的长字符串

#### 第三步：设置数据库表

1. 点击左侧 "SQL Editor"
2. 复制 `docs/supabase-setup.sql` 中的 SQL 代码
3. 粘贴到编辑器中并点击 "Run" 执行
4. 确认表创建成功

#### 第四步：配置编辑器

1. 打开编辑器，点击 `文件` → `云同步管理`
2. 在 "配置设置" 标签页中填写：
   - **项目 URL**: 粘贴第二步获取的 URL
   - **API Key**: 粘贴第二步获取的 anon public key
   - **用户 ID**: 输入您的唯一标识符（如邮箱）
   - **设备名称**: 给当前设备起个名字
3. 点击 "测试连接" 确认配置正确
4. 点击 "启用同步"

#### 第五步：设置数据加密（推荐）

1. 切换到 "安全设置" 标签页
2. 开启 "启用数据加密"
3. 点击 "设置主密码" 并输入强密码
4. 妥善保管主密码（无法找回！）

#### 第六步：开始同步

- **上传**: 将本地数据上传到云端
- **下载**: 从云端下载数据到本地
- **同步**: 智能双向同步，自动处理冲突

### 2. 手动备份 (备用方案)

**优点：**

- ✅ 简单易用，无需配置
- ✅ 完全离线，数据安全
- ✅ 支持选择性导入导出

**使用方法：**

1. 点击 `文件` → `导出所有数据`
2. 保存 JSON 文件到安全位置
3. 在新设备上点击 `文件` → `导入所有数据`
4. 选择之前导出的 JSON 文件

## 📱 多设备使用流程

### 设备 A（主设备）

1. 完成 Supabase 同步配置
2. 设置主密码（如果启用加密）
3. 点击 `上传` 备份数据到云端
4. 确认同步成功

### 设备 B（新设备）

1. 打开编辑器，配置相同的 Supabase 连接
2. 输入相同的主密码（如果启用加密）
3. 点击 `下载` 获取云端数据
4. 开始使用，数据已同步

### 设备 C（第三台设备）

1. 重复设备 B 的配置步骤
2. 所有设备将保持数据同步

### 日常使用建议

- **自动同步**: 启用后会定期自动同步
- **手动同步**: 重要修改后可手动点击 `同步`
- **冲突处理**: 系统会自动检测并提示解决冲突
- **离线使用**: 支持离线编辑，联网时自动同步

## ⚠️ 注意事项

### 数据安全

- **主密码保护**: 启用加密后，主密码无法找回，请务必记住
- **API 密钥安全**: Supabase API Key 请妥善保管，不要泄露
- **定期备份**: 建议同时使用云同步和本地备份双重保险
- **敏感数据**: API 密钥等敏感信息会自动加密存储

### 同步冲突处理

- **自动检测**: 系统会自动检测数据冲突
- **解决策略**:
  - **使用本地**: 用本地数据覆盖云端
  - **使用云端**: 用云端数据覆盖本地
  - **智能合并**: 自动合并两边的数据（推荐）
- **预防冲突**: 建议一次只在一台设备上编辑

### 网络要求

- **在线同步**: 需要稳定的网络连接
- **离线支持**: 支持离线使用，联网时自动同步
- **错误处理**: 同步失败时会显示详细错误信息和解决建议

## 🔧 故障排除

### 常见问题

**Q: 连接测试失败**
A: 检查 Supabase URL 和 API Key 是否正确，确认网络连接正常

**Q: 数据库表不存在**
A: 确认已在 Supabase SQL 编辑器中执行了建表脚本

**Q: 主密码忘记了**
A: 主密码无法找回，只能清除密码并重新设置（会丢失加密数据）

**Q: 同步冲突如何处理**
A: 选择合适的解决策略：使用本地、使用云端或智能合并

**Q: 自动同步不工作**
A: 检查网络连接，确认已启用自动同步且设置了合理的同步间隔

**Q: 数据上传失败**
A: 检查数据大小是否超限，确认 Supabase 项目状态正常

### 数据恢复

如果遇到数据问题，可以通过以下方式恢复：

1. **从云端恢复**: 点击 `下载` 按钮从 Supabase 恢复数据
2. **从本地备份恢复**: 使用 `导入数据` 功能恢复 JSON 备份文件
3. **从浏览器恢复**: 检查浏览器的 localStorage 数据
4. **从 Supabase 控制台恢复**: 直接在 Supabase 表编辑器中查看和恢复数据

### 性能优化

- **定期清理**: 使用高级选项中的清理功能删除旧数据
- **合理设置同步间隔**: 不要设置过于频繁的自动同步
- **网络优化**: 在网络较差时暂时关闭自动同步

## 🎯 最佳实践

1. **定期备份**: 每周至少进行一次完整备份
2. **多重保险**: 同时使用云同步和本地备份
3. **测试恢复**: 定期测试数据恢复流程
4. **版本管理**: 重要修改前创建备份点
5. **安全意识**: 保护好 GitHub Token 和备份文件
